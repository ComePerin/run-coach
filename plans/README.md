# Plans

One folder per plan, created by the `coros-coach` skill or `scripts/plan.py init <slug> …`:

- `plan.yaml` — source of truth (see `.claude/skills/coros-coach/references/plan-schema.md`)
- `plan.md` — generated by `scripts/plan.py render` / `sync` (do not edit)
- `journal.md` — append-only coaching log
- `reports/YYYY-MM-DD.md` — training-status reports (`scripts/report.py`, `coros-report` skill)
