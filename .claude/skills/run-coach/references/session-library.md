# Session library

Key sessions with prescriptions relative to the athlete's **threshold pace T** (s/km). Compute paces with
`plan.py zones` (Easy 1.18–1.32·T, Marathon 1.05–1.08·T, Threshold 0.98–1.02·T, Interval 0.93–0.96·T,
Repetition 0.86–0.90·T). Example values are for T = 3:55/km (235 s).

Durations include warm-up/cool-down unless stated. "WU" = warm-up, "CD" = cool-down. Quality sessions normally
start with 15′ easy WU (+ 4 strides for I/R sessions) and end with 10′ easy CD.

## Race-specific

| Goal | Key sessions in the last 6–8 weeks |
|---|---|
| 5K | 5 × 1000 @ I; 10–12 × 400 @ R; tempo 20′; race-pace 3 × 1600 @ 5K pace, 3′ |
| 10K | 6 × 1000 @ I; 3 × 2 km @ T; 4 × 2 km @ 10K pace, 2′ |
| Half | 3 × 3 km @ T; 2 × 5 km @ half pace (≈ 1.02·T); long run 90–110′ with last 20–30′ @ M/half pace |
| Marathon | long run 26–32 km with last 8–16 km @ M (1.05–1.08·T); medium-long 18–24 km; 2 × 20′ @ T; 16 km @ M |
| Trail | long runs on terrain (time, D+), climb repeats, back-to-back long weekend, downhill technique, HR/effort targets rather than pace |

## Rules when choosing sessions

- 1 long run + ≤ 2 quality sessions per week (≤ 3 with ≥ 6 runs/week), never on consecutive days.
- Base: 1 quality (fartlek, hills, progression) + strides. Build: T + I. Peak: race-pace + T. Taper: short, sharp
  reminders (e.g. 3 × 1000 @ race pace), volume −40–60 %.
- Rotate stimuli week to week; progress by adding reps/duration before increasing pace.
- In recovery weeks keep one shortened quality session.
- Respect time budget: if the weekly minutes are short, cut easy volume before cutting the key sessions.
- Never prescribe a session type the athlete has not done in the last 8 weeks at full volume: start at ~60 %.
